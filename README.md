In this Project I used:
VLANs (HR, Sales, Finance, IT, Guest, Management, Blackhole)
Trunks between the switches
Inter-VLAN routing
IPv4 addressing
IPv6 addressing
DHCP (on both core switches)
Static routing
Dynamic routing (OSPF)
ACLs (Guest isolation, Finance protection, SSH access only from IT)
SSH
Passwords and login banner
Port security
BPDU guard and PortFast
DHCP snooping
Unused ports shut down
Rapid spanning tree
HSRP (gateway redundancy)
EtherChannel
Redundant uplinks (every access switch connected to both core switches)
Guest Wi-Fi (access point and wireless laptop)
Internet server (web and DNS)
